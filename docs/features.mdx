# Features

Product capabilities and workflows readers can use or operate. This page is the entry point — start with whichever sub-page maps to the workflow you're trying to complete and use the rest as you go deeper.

[AI Responses](/docs/features/ai-responses) — AI responses turn retrieved context into a concise answer for the person asking the question. [Conversation Memory](/docs/features/conversation-memory) — Conversation memory keeps recent messages so follow-up questions can use nearby context. [Documentation Lookup](/docs/features/documentation-lookup) — Documentation lookup finds relevant docs context before the project answers a user question. [Messaging Bot](/docs/features/messaging-bot) — The project runs as a messaging bot that listens for chat messages and replies inside a connected platform.
