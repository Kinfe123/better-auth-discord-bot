# Quickstart

Use this quickstart to move from a fresh checkout to the first workflow that proves Better Auth Docs Discord Bot is configured and usable.
## Before You Start
This project uses `bun` as its package manager.
Environment-backed behavior is present, so configuration is part of the first-run path.
## First Run Path
1. Install dependencies with `bun install`.
2. Copy `.env.example` to `.env` and set the required values.
3. Run `bun run dev` to exercise the main workflow.
4. Send a command such as `!docs how do I set this up?` in a test channel.
## Expected Result
The bot should acknowledge the question and return a useful answer in the same channel. If it stays silent, check the bot token, platform permissions or intents, and any AI/provider keys listed on the environment page.
## Useful Commands
These commands are useful after the first run because they are the repeatable workflows available in the project.
- `build`: `tsc` creates the production build or compiled package artifacts.
- `start`: `node dist/index.js` starts the runtime entrypoint after dependencies or build output are ready.
- `dev`: `ts-node src/index.ts` starts the local development workflow.
